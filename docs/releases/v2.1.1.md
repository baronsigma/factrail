# FACTRAIL v2.1.1 — Public release hardening

FACTRAIL has grown from individual company and Trade tools into evidence infrastructure for AI agents. This release prepares the existing architecture for public operation. It adds no new data domain.

Evidence Contract 1.1 represents facts, source provenance, freshness, coverage, and explicit conflicts. Immutable receipts identify each evidence observation; state fingerprints identify substantive state across observations. Supported Evidence Core paths are French company verification and structured EU import assessment. Private demand telemetry records capability gaps without storing raw identifiers or request content.

Version 2.1.1 tightens receipt validation, MCP schemas and descriptions, readiness responses, SQLite startup behavior, telemetry categories, and operator documentation. The legacy `verify_french_company`, `assess_import`, and experimental `analyze_company` tools remain available with compatible response shapes.

Import classification and tariff estimates remain indicative where live authoritative sources are unavailable. The experimental `analyze_company` tool returns placeholder financial and credit figures; it is not verified risk analysis. The hosted endpoint's `tools/list` response determines which source-version tools are deployed.

This file is release text for review. It is not a published GitHub release.
